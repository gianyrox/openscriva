# Screenplay / script

A film, TV, or stage script laid out as scenes across three acts, with characters and a main dramatic line already tracked. The AI keeps your action filmable and your dialogue lean.

## A note on format

OpenScriva's editor is prose-markdown, not dedicated screenplay software. This template uses a **markdown convention** for script format:

- Scene headings are H2 sluglines: `## INT. KITCHEN — NIGHT`
- Character cues are bold: `**MAYA**`, with the dialogue on the next line
- Action lines are plain present-tense paragraphs

It reads cleanly and exports cleanly, and the AI is told to follow it. It is not a replacement for industry-standard tools when you need exact Final Draft formatting — treat this as drafting the script's substance, with format you can convert later.

## What you get

- **A 7-scene, three-act skeleton** with sluglines in place — open, inciting incident, complication, midpoint, low point, climax, resolution.
- **A lead character** in the mind, and a main **A-story** plot thread to track.
- **Script writing rules:** present tense, objective/cinematic POV, distinct dialogue per character, cut anything unfilmable, and the markdown format convention above.
- **Voice profile** calibrated to screenwriting, so the AI drafts action and dialogue in the right register.

## How to use it

1. Set the format (feature / pilot / play), the logline, and your lead.
2. Fill in real sluglines and write. When the AI slips into novelistic interiority — a thought we can't film — the rules already tell it not to.
3. Add each character as they appear, with a one-line want. Distinct wants make distinct dialogue.
4. Use **critique** to check each scene turns on something.

Because this uses the "custom" writing type, only the features a script needs are on. Turn on world-building if your story needs a tracked world.
